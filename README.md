# Mizan Yatırım — Acquisition Campaign Analytics

Marketing analytics case study for a **fictional participation-finance (Islamic-compliant) brokerage**. All data is synthetic.

**Question:** Which Q3 2026 acquisition campaign brought valuable investors, how should the Q4 budget be split, and what happened to customers holding a stock that lost compliance in the August screening?

**Stack:** BigQuery (SQL), Python (synthetic data), GitHub

> Work in progress. See [`docs/requirements.md`](docs/requirements.md) for the scope and metric definitions.
